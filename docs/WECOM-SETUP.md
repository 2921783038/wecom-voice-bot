# 企业微信接入教程（从零到能收发消息）

面向个人开发者：一个人、一个手机号，也能注册企业微信并跑起自建应用。

## 一、注册

1. 打开 [work.weixin.qq.com](https://work.weixin.qq.com)，点「立即注册」
2. 填企业名称（随便填，比如「我的测试团队」）、行业、规模、管理员姓名与手机号
3. 用微信扫码验证，完成注册

个人注册不需要营业执照。注册完你会同时拥有一个「企业微信管理后台」和一个企业微信 App 账号。

## 二、拿 CorpID

管理后台 → **我的企业** → **企业信息** → 拉到最下面 → **企业ID**，形如 `ww1a2b3c4d5e6f7g8h`。

这个值是下面所有配置的基础。

## 三、创建自建应用

1. 管理后台 → **应用管理** → 应用 → **自建** → **创建应用**
2. 上传 logo、填应用名称（比如「助手」）、选择可见范围（至少包含你自己）
3. 创建后进入应用详情，记下两个值：
   - **AgentId**：一串数字，如 `1000002`
   - **Secret**：点「查看」并发送到企业微信 App，形如 `abcDEF123...`

## 四、配置接收消息（回调）

应用详情 → **接收消息** → **设置API接收**，填三项：

| 字段 | 怎么填 |
| --- | --- |
| URL | `https://你的域名/wecom/callback`，必须公网可达且是 HTTPS |
| Token | 自己定一个随机串，例如 `wcom_` + 16 位随机字符 |
| EncodingAESKey | 点「随机获取」，43 位 |

点保存时，企业微信会立刻向这个 URL 发一个 **GET** 请求做验证：

```
GET /wecom/callback?msg_signature=...&timestamp=...&nonce=...&echostr=...
```

服务端必须**解密 `echostr` 并原样返回明文**，否则保存失败。
`wecom_server.py` 已经处理了这一步，但前提是服务已经起来、并且 `.env` 里的
`WECOM_CALLBACK_TOKEN` / `WECOM_AES_KEY` 和后台填的一致。

> 常见卡点：URL 保存报「回调地址校验失败」，九成是服务没启动、证书无效，或者 Token/AESKey 对不上。

## 五、配置可信 IP

应用详情 → **企业可信IP** → 添加你的服务器出口 IP。

不配的话，调用发消息接口会返回 `60020`（not allow to access from your ip）。

服务器出口 IP 用这条命令看：

```bash
curl -s https://ifconfig.me
```

## 六、确认能收到消息

1. 通讯录 → 成员 → 确保你自己在应用可见范围内
2. 用手机上的**企业微信 App**（微信扫码即可登录）给这个应用发一条消息
3. 看服务端日志是否收到回调

个人号想在自己的微信里收到企业微信消息，需要把「微信插件」开启：
管理后台 → 我的企业 → 微信插件 → 扫码关注，之后微信里会多一个企业微信消息入口。

## 七、把值填进 .env

```bash
WECOM_CORP_ID=ww1a2b3c4d5e6f7g8h
WECOM_AGENT_ID=1000002
WECOM_SECRET=abcDEF123...
WECOM_CALLBACK_TOKEN=wcom_xxxxxxxxxxxxxxxx
WECOM_AES_KEY=43位随机串
```

启动：

```bash
python3 wecom_server.py
```

## 八、自检清单

| 检查项 | 命令 / 位置 |
| --- | --- |
| 服务在跑 | `curl -s http://127.0.0.1:18114/` |
| 回调可解密 | 后台重新保存一次回调配置，能保存成功即通过 |
| 可信 IP 已配 | 应用详情「企业可信IP」里有你的出口 IP |
| 成员可见 | 通讯录里你在应用可见范围 |
| 能取 token | 日志里 `gettoken` 返回 `errcode: 0` |

## 常见错误码

| errcode | 含义 | 处理 |
| --- | --- | --- |
| `40001` | secret 不对 | 重新在后台取一次 |
| `40013` | corpId 不对 | 核对「企业ID」 |
| `60020` | IP 不在可信列表 | 加可信 IP |
| `81013` | 部门/成员不在范围 | 调整应用可见范围 |
| `45009` | 接口调用超限 | 降低频率 |

## 关于语音

企微语音消息是 **AMR-NB** 格式，且回调 XML 里可能自带 `Recognition` 字段（企微已经转好的文字）。
服务端会优先用 `Recognition`，没有再下载 AMR 转码后送去识别，具体见根目录 README。
